# Sales Data Analysis and Machine Learning

## Project Overview

This project focuses on analyzing sales data using Python and Jupyter Notebook.
The analysis includes data cleaning, exploratory data analysis, visualization,
monthly sales trend analysis, machine learning model development, and model evaluation.

## Objectives

- Understand the sales dataset
- Perform data cleaning and preprocessing
- Analyze sales trends
- Visualize monthly sales performance
- Build a machine learning model
- Evaluate model performance using RMSE and R² Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Analysis Performed

### 1. Data Loading
The dataset was imported into Python using Pandas.

### 2. Data Cleaning
The dataset was checked for missing values, duplicate records, and incorrect data types.

### 3. Exploratory Data Analysis
Different statistical summaries and visualizations were used to understand the dataset.

### 4. Monthly Sales Trend
Monthly sales were calculated and visualized using a line chart to identify changes
in sales over time.

### 5. Machine Learning
A regression model was developed to predict the target variable.

### 6. Model Evaluation

The model was evaluated using:

- RMSE
- R² Score

## Results

RMSE: 23619.2892

R² Score: 0.0332

## Conclusion

The project demonstrates the complete workflow of a sales data analysis and
machine learning project, from data preprocessing and visualization to model
development and evaluation.
